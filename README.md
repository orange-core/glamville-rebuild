# Wesconnett Restoration — OrangeCore website concept

A responsive, static website prototype for a Jacksonville, Florida property restoration business. Reused the existing OrangeCore static-site repository as a starting point; the repository can be renamed after the prototype is reviewed.

## Demo pages
- `index.html` — conversion-focused homepage with service cards, process, about, insurance guidance and contact form
- `water-damage.html` — dedicated water-damage service page
- `css/main.css` — shared responsive styling
- `js/main.js` — mobile navigation and local demo-form behaviour

## Important demo notes
- This is a concept preview, not an official business website.
- Contact number, service area, service availability, company history, qualifications, response times and insurance practices must be verified with the owner before public launch.
- No unverified “on-site in 60 minutes”, licensing, certification, direct insurance billing or response-rate claims are made.
- The contact form does not submit to a server or send an email. It prepares/copies an enquiry message locally.
- External Unsplash images are placeholders and should be replaced with approved business photography before production.
- The other service/navigation items on the homepage are concept sections, not separately implemented pages. The water-damage page is the second polished demo page.
